# System Design

## 总体架构

```
┌─────────────────┐         HTTP/REST          ┌─────────────────────┐
│   tarot-ai      │ ──── 扣减抽卡次数 ────────▶│   big-market        │
│  （AI 应用层）   │ ◀─── 查询剩余次数 ──────── │  （营销平台）        │
│                 │ ◀─── 签到回调加次数 ───────│                     │
└─────────────────┘                            └─────────────────────┘
```

**拆分为两个独立的项目，通过HTTP接口打通关键节点**
理由如下：
- 能够完整学习大营销项目的设计
- 写到简历中能够有不同的侧重点
|项目|面试重点|
|-------|-------|
|大营销|DDD、责任链、规则引擎、分库分表、高并发库存扣减|
|塔罗 AI |LLM 集成、Prompt 工程、SSE 流式输出、结构化输出解析|
