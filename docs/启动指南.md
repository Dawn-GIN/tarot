# 项目启动指南

AI 塔罗牌占卜应用，包含 Spring Boot 后端（`tarot-api`）与 React 前端（`tarot-ui`）。

## 一、环境依赖

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17+ | 编译目标为 17，可在 21 上运行 |
| Maven | 3.9+ | 构建后端 |
| Node.js | 18+ | 运行前端 |
| MySQL | 8.0+ | 存储牌型、卡牌、占卜历史 |
| Redis | 7+ | 存储占卜会话（sessionId） |
| Docker | 可选 | 用于快速启动 Redis |

## 二、准备工作

### 1. MySQL：创建数据库

后端启动时会自动执行 `schema.sql` 建表并用 `data.sql` 填充 78 张牌和 3 种牌型，但数据库本身需要先手动创建：

```sql
CREATE DATABASE IF NOT EXISTS tarot DEFAULT CHARSET utf8mb4;
```

### 2. Redis：启动服务

已安装 Redis 可直接启动；或用 Docker 一键拉起：

```powershell
docker run -d --name tarot-redis -p 6379:6379 redis:7-alpine
```

后续复用同一容器：

```powershell
docker start tarot-redis   # 启动
docker stop tarot-redis    # 停止
```

### 3. 配置环境变量（密钥）

后端通过环境变量读取密钥，**不要把密钥写进代码或提交到 git**。项目使用 `spring-dotenv`，在 `tarot-api/` 目录下放一个 `.env` 文件即可自动加载。

复制模板并填入真实值：

```powershell
cd tarot-api
copy .env.example .env
```

`.env` 内容示例（`.env` 已被 `.gitignore` 忽略）：

```
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_DB=tarot
MYSQL_USER=root
MYSQL_PASSWORD=你的MySQL密码

REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=
REDIS_DB=0

LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_API_KEY=你的智谱GLM密钥
LLM_MODEL=glm-4-flash
```

## 三、启动后端

在 `tarot-api/` 目录下操作（spring-dotenv 从当前目录读取 `.env`）：

```powershell
cd tarot-api

# 首次或改动代码后需重新打包
mvn install -DskipTests

# 启动
java -jar tarot-api-app\target\tarot-api.jar
```

启动成功标志：日志出现 `Started TarotApplication in x seconds`，服务监听 `http://localhost:8080`。

健康检查：

```
http://localhost:8080/actuator/health
```

返回 `{"status":"UP",...}` 表示后端、MySQL、Redis 均正常。

> 注意：重新打包前必须先停掉正在运行的后端（终端按 `Ctrl+C`），否则 jar 文件被占用导致打包失败。

## 四、启动前端

```powershell
cd tarot-ui

# 首次需安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 `http://localhost:5173`。前端已配置代理，`/api` 请求自动转发到后端 `localhost:8080`（见 `vite.config.js`）。

## 五、完整占卜流程验证

在浏览器打开 `http://localhost:5173`：

1. 输入问题，点击「开始占卜」——后端调用 LLM 选择牌型
2. 点击弧形牌堆抽卡——后端随机发牌并分配位置，抽满后自动翻牌
3. 点击「开始解牌」——后端第二次调用 LLM，通过 SSE 流式返回解读，逐字呈现

## 六、接口速查

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/tarot/start` | POST | 开始占卜，入参 `{question}`，返回 `sessionId` 和牌型 |
| `/api/tarot/draw` | POST | 抽一张牌，入参 `{sessionId}`，需调用 `cardCount` 次 |
| `/api/tarot/interpret` | GET (SSE) | 流式解读，参数 `?sessionId=xxx` |
| `/api/credit/balance` | GET | 查询剩余占卜次数（当前为桩实现） |
| `/actuator/health` | GET | 健康检查 |

## 七、停止服务

- 后端 / 前端：对应终端窗口按 `Ctrl+C`
- Redis 容器：`docker stop tarot-redis`
