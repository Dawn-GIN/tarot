## 前置：连接服务器

```bash
ssh root@47.100.85.136
```

---

## 一、Docker 容器管理

```bash
# 查看所有容器状态
docker compose ps

# 查看后端日志（实时跟踪,Ctrl+C 退出）
docker compose logs -f backend

# 查看最近 50 行后端日志
docker compose logs --tail 50 backend

# 查看所有服务日志
docker compose logs -f

# 重启某个服务
docker compose restart backend

# 停止所有服务
docker compose --env-file .env.production down

# 启动所有服务
docker compose --env-file .env.production up -d

# 查看容器资源占用（CPU/内存）
docker stats
```

---

## 二、查看数据库

进入 MySQL 容器的命令行：

```bash
docker exec -it tarot-mysql mysql -uroot -pTarot@2026
```

进入后就是 MySQL 交互界面：

```sql
-- 切换到 tarot 数据库
USE tarot;

-- 查看所有表
SHOW TABLES;

-- 查看占卜历史记录
SELECT * FROM tarot_history ORDER BY id DESC LIMIT 10;

-- 查看牌阵
SELECT * FROM spread;

-- 查看卡牌（前10张）
SELECT id, name, arcana FROM card LIMIT 10;

-- 查看某张牌的正逆位解释
SELECT name, upright_meaning, reversed_meaning FROM card WHERE id = 0;

-- 退出 MySQL
EXIT;
```

## 三、查看 Redis（会话数据）

```bash
docker exec -it tarot-redis redis-cli -a Tarot@2026

# 查看所有 key
KEYS *

# 查看某个 session 内容
GET tarot:session:你的sessionId

# 退出
EXIT
```

## 四、常用 Linux 命令

```bash
# 查看磁盘使用
df -h

# 查看内存使用
free -h

# 查看 CPU 和进程
top          # 按 q 退出

# 查看某个端口是否在监听
ss -tlnp | grep 80

# 查看服务器公网 IP
curl ifconfig.me
```

## 五、文件操作

## 六、更新部署

当你本地改了代码想更新线上：

```bash
# 1. 本地: 打包后端
cd d:\DAWN\tarot-ai\tarot-api
mvn clean package -DskipTests -q

# 2. 本地: 重新构建镜像
cd d:\DAWN\tarot-ai
docker compose build

# 3. 本地: 导出镜像
docker save tarot-ai-backend tarot-ai-frontend -o tarot-images.tar

# 4. 本地: 传到服务器
scp tarot-images.tar root@47.100.85.136:/root/

# 5. 服务器上: 加载新镜像并重启
docker load < /root/tarot-images.tar
docker compose --env-file .env.production down
docker compose --env-file .env.production up -d
```

## 七、常见问题排查

| 现象 | 排查命令 |
|------|----------|
| 页面打不开 | `docker compose ps` 看容器是否在运行 |
| 后端报错 | `docker compose logs --tail 50 backend` |
| 数据库连不上 | `docker compose logs mysql` |
| 磁盘满了 | `df -h` + `docker system prune` 清理无用镜像 |
| 想看实时请求 | `docker compose logs -f backend` 然后操作页面 |
